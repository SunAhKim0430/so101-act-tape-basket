# 2. 시연 녹화

로봇 PC에서 합니다. 리더 팔로 팔로워를 조종하는 동안 카메라 영상, 팔로워 관절 값(state), 리더 관절 값(action)이 30fps로 저장됩니다.

## 2-1. 설정 (`config.bat`)

| 항목 | 값 | 비고 |
|---|---|---|
| fps | 30 | |
| 해상도 | 640×480 | |
| 카메라 | `front` 1대 | 녹화를 시작하면 카메라 구성을 바꿀 수 없음 (실행 때도 같은 구성) |
| 에피소드 최대 길이 | 30초 | 실제 작업은 15~20초. 끝나면 바로 `n` |
| 리셋 시간 | 60초 | 녹화 안 됨. 준비되면 `n`으로 넘어감 |
| 세션당 개수 | 5개 (`test`는 3개) | 같은 명령을 여러 번 실행해 개수를 채움 |
| 작업 문장 | `Grab the yellow tape and put in the basket` | |
| 저장 위치 | `%USERPROFILE%\so101_data\pilot\`, `...\main\` | 실행할 때마다 `<이름>_<날짜_시간>` 새 폴더 |

## 2-2. 명령

```bat
4_record.bat test            시험 녹화 3개 → so101_data\pilot\test_<시간>
4_record.bat main pos1       본 녹화 5개   → so101_data\main\pos1_<시간>
4_record.bat main pos1 3     3개만 (일찍 끝낸 세션 보충)
6_view.bat                   녹화 목록
6_view.bat main\pos1_<시간> 2   에피소드 2를 영상 + 관절 그래프로
```
- `pos1`은 폴더 이름에 붙는 표시입니다. 테이프 자리별로 다르게 붙여 두면 나중에 구분하기 쉽습니다.
- 우리는 `main pos1`, `main pos4`, `main pos7`로 5개씩 3번 녹화했고(15개), 테이프는 세 번 모두 거의 같은 자리였습니다. 공개한 모델이 이 15개로 학습한 것입니다. 처음에는 **한 자리에서 15~20개**로 학습해 실행이 되는지 보고, 그다음 자리를 늘리는 것을 권장합니다.

## 2-3. 진행 과정

```text
4_record.bat 실행 → 팔로워가 리더 자세로 이동, rerun 창(카메라 화면) 열림
│
├─ "Recording episode 0" ─ [녹화, 최대 30초]
│     시작 자세 → 테이프 잡기 → 바구니에 넣기 → 시작 자세 → n
│
├─ "Reset the environment" ─ [리셋, 녹화 안 함, 최대 60초]
│     테이프를 꺼내 같은 자리에 놓기, 리더를 시작 자세에 → n
│
├─ [저장, 약 1분] 영상 인코딩(AV1). 터미널에 Svt[info] 줄, 화면은 멈춘 것처럼 보임
│     기다리기. 이때 누른 n / r은 무시됨 (record.py)
│
├─ "Recording episode 1" ─ ... 반복
│
└─ 마지막 에피소드 → n → 저장 → "Stop recording" → 자동 종료
      → 정지 프레임 통계 출력 (2-6) → 옮길 폴더 안내
```

- 음성 안내는 Windows 기본 음성(PowerShell)이 읽어서 1~2초 늦을 수 있습니다. **정확한 시작 기준은 터미널의 `Recording episode N` 줄**입니다.
- 한 세션(5개) 약 8분.

## 2-4. 키

| 키 | 녹화 중에 누르면 | 리셋 중에 누르면 |
|---|---|---|
| `n` (→) | 에피소드 끝 → 리셋으로 | 리셋 끝 → 방금 에피소드 저장 → 다음 녹화 |
| `r` (←) | 지금 것을 버림 → 리셋 후 같은 번호 다시 | 방금 찍은 것(저장 전)을 버림 → 다시 |
| `q` (Esc) | ⚠ 찍던 **미완성 에피소드까지 저장**하고 종료 | 방금 에피소드 저장 후 종료 |

- 정해진 개수를 다 찍으면 저절로 끝납니다. `q`는 일찍 끝낼 때만, **리셋 중에** 누릅니다.
- 실패하거나 머뭇거렸으면 바로 `r`.
- **창 닫기 금지.** 에피소드 정보는 세션이 끝날 때 한꺼번에 기록됩니다. 창을 닫으면 그 세션 폴더 전체를 못 쓸 수 있습니다.
- 키는 어느 창에서 눌러도 먹힙니다. 녹화 중에 다른 창에서 타자 치지 않습니다.

## 2-5. 시연 방법

1. 시작 자세는 하나로 (그리퍼 열림/닫힘까지). 리셋 때 리더에서 손을 떼야 하므로 리더가 혼자 버티는 자세가 편합니다.
2. `Recording episode` 줄이 뜨면 **바로 움직입니다.** 처음에 가만히 있는 시간도 그대로 학습됩니다 (실행할 때 머뭇거림).
3. 잡는 방향·방식, 옮기는 경로를 매번 비슷하게.
4. 넣고 시작 자세로 돌아오면 즉시 `n`.
5. 실패한 시연은 섞지 않습니다 (`r`).
6. 한 세션 동안 테이프는 같은 자리에. 카메라·바구니·조명은 모든 세션에서 그대로.

## 2-6. 세션이 끝나면 나오는 통계 (`ep_stats.py`)

```text
ep002 len= 20.1s  video 0:45.3~1:05.4  idle head= 1.8s tail= 1.7s  grip=[0,35]  start=[ -1. -104. 95. -103. -7. 0.]
idle fraction : 22%  (aim for < 15%)
active length : median 17.3s  min 16.6s  max 18.4s
start pose std: [1.7 0.  0.4 0.1 5.8 0.4]  (degrees per joint, smaller = more consistent)
```
- `idle fraction`: 움직임이 없는 프레임 비율. 15% 미만 목표. 우리 15개는 22~25%였고 대부분 시작 직후 3~5초였습니다 (그래도 성공).
- `start pose std`: 시작 자세가 얼마나 일정한지(관절별 각도 표준편차). 작을수록 좋음.
- `check these`: 움직임이 없거나 정지가 30% 넘는 에피소드 → `6_view.bat`으로 확인하고, 이상하면 학습에서 뺍니다 ([3. 학습](3_train.md)).
- `video`: 세션의 에피소드가 mp4 하나에 이어 붙어 있어서, 각 에피소드가 영상의 몇 분 몇 초인지 표시합니다.

## 2-7. 녹화 영상 보기

| 방법 | 위치 |
|---|---|
| 영상 파일 | `<세션 폴더>\videos\observation.images.front\chunk-000\file-000.mp4` (세션 전체가 한 파일). AV1이라 VLC나 Chrome/Edge에 끌어다 놓기 |
| 영상 + 관절 그래프 | `6_view.bat main\pos1_<시간> 2` (rerun 창, 학습에 들어가는 그대로) |

## 2-8. 학습 PC로 옮기기

세션 폴더를 **통째로**(`meta\`, `data\`, `videos\`) 학습 PC의 이 저장소 `datasets/incoming/` 안에 넣습니다. 시험 녹화는 `datasets/pilot/`에.

```text
datasets/incoming/
├── pos1_20261106_183919/
│   ├── meta/      info.json, stats.json, tasks.parquet, episodes/...
│   ├── data/      chunk-000/file-000.parquet   (프레임별 action, state)
│   └── videos/    observation.images.front/chunk-000/file-000.mp4
├── pos4_.../
└── pos7_.../
```
- mp4만으로는 학습할 수 없습니다. 관절 값은 `data/`, 에피소드 경계와 정규화 값은 `meta/`에 있습니다.
- 옮기는 방법은 자유입니다 (`scp -r`, USB, 공유 폴더). zip으로 옮겼으면 그 자리에서 풉니다.
